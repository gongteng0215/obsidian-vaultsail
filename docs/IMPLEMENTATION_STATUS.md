## 发布门槛

0.1.16 依据真实 iPad「保存本机密钥失败」进一步定位根因：配对生成的两个 SecretStorage 标识长度为 94/91，而 Obsidian 实际实现只接受小写字母、数字、短横线及最多 64 字符。只读检查本机 Obsidian 1.14.4 程序代码，并用其原始 validateId/setSecret 方法和虚拟存储执行验证，旧标识被拒绝、新标识 62/59 字符均被接受，未接触用户凭据。改为设备 Hash 范围加随机独立后缀，更新会话归属识别和旧引用清理，旧配置和加密配对格式兼容。模拟密钥存储补齐真实 64 字符限制，修复前复现失败；修复后 90 项测试、类型检查、构建、ZIP 校验通过，覆盖再次导入、失败回滚、重启保持授权及复制配置不继承其他设备会话。真实 iPad 更新后的最终导入仍待维护者确认。社区保持归档，仅发布 GitHub 预览包。
