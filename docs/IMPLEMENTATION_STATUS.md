# 实施状态（2026-10-15）

当前版本：**0.1.14**。已完成核心代码实施及模拟验证；真实账号和 iPad 验收未完成。GitHub 公开安装包与社区目录审核是独立流程，不代表稳定性验收已经完成。0.1.3 修复密钥选择会话项后被清空的问题，增加独立工作台与明确保存状态；0.1.4 增加授权页自动打开、可见等待状态、15 秒超时与即时逻辑取消。0.1.5 自动补齐并保存默认应用目录 /apps/VaultSail，保留已有自定义目录。0.1.6 增加未绑定时的云端库创建/选择引导，并区分账号、目录变更错误。后续稳定里程碑必须以真实验收结果为准。

当前用户应用的公开设备码请求已在开发机只读核验：HTTP 200，设备码和官方 HTTPS 授权链接正常返回。未记录实际 AppKey 或设备码；未使用用户 SecretKey，也未代替用户登录。该结果不能代表 Token 交换或文件接口通过。

## 发布门槛

`0.1.2` 已提供本地候选安装包供用户进行真实授权和安装验收。正式创建该版本的 GitHub Release 前，应完成至少一次真实安装、授权与手动文件往返检查；无法访问用户自己的应用时不代替用户签署验收。

历史 0.1.1 是 D0 原型，不代表当前能力。按用户新的发布与清理请求准备 0.1.12；公开版本附带三个插件文件、安装 ZIP、SHA256SUMS 和明确的验证边界。公开下载不代表社区目录已经审核通过，也不代表真实移动端验收完成。

0.1.7 自动化验证：70 项测试通过，含无 errno 的 PCS 分片响应、不同错误码字段、HTTP 403 权限错误、无效和不匹配 MD5 禁止发布元数据。截图只能确认旧解析器拒绝了响应，真实账号此次失败的具体接口尚待本地重试核验。

0.1.8 完成目录与已校验对象缓存优化，模拟请求减少 48.3%；真实速度尚未测量。缓存变化、缺少指纹及跨设备记录均覆盖回归测试；见 [性能记录](PERFORMANCE.md)。

0.1.9 完成阶段进度与耗时、设备本地最近成功记录、云端文件/版本清单、配对配置文件与文本导入导出。76 项自动化测试通过，含模拟独立设备授权、导入后待验证绑定与权限门槛、配置隐私和排除、进度失败不计完成。真实 iPad 与 100 文件真实网盘测试仍未验收；见 [配对流程](PAIRING.md)。

0.1.10 新增一键同步与自动冲突副本，改用批次边界扫描、独立设备记录缓存，并优化基线/重命名查找。81 项测试通过。模拟 100 文件首次上传 1505→1208 次请求，重启后的记录扫描 206→6 次请求；实际网盘速度和 iPad 仍未由开发者验收。

0.1.11 按用户更新的需求允许迁移授权：密码加密配对码/文件包含 SecretKey 与授权令牌；目标设备自动检查实际账号、库标识、完整目录枚举和 1 KB 往返后保存到本设备 SecretStorage，无需重复网页登录。增加 24 小时导入窗口、字段白名单、密码确认、设备独立引用及失败回滚；普通续期网络错误保留本地授权。86 项测试通过并完成构建。真实 iPad 加解密、密钥保存、跨端实际续期仍待验收；小文件配对验证不替代完整 20 MiB 实测。

0.1.12 清理界面测试预览标识和过时冲突说明，整理用户文档与社区提交资料，统一作者与发布元数据，在安装文件内保留 MIT 和依赖许可。删除旧本地安装包及可再生临时产物，保留测试源码、恢复备份和用户配置。社区正式提交需要维护者在官方目录登录、关联 GitHub 并接受政策；提交状态以官方页面为准。
