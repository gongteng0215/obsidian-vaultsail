# 实施状态（2026-10-14）

当前版本：**0.1.4 测试候选版**。已完成核心代码实施及模拟验证；真实账号和 iPad 验收未完成。0.1.3 修复密钥选择会话项后被清空的问题，增加独立工作台与明确保存状态；0.1.4 增加授权页自动打开、可见等待状态、15 秒超时与即时逻辑取消。后续稳定里程碑必须以真实验收结果为准。

当前用户应用的公开设备码请求已在开发机只读核验：HTTP 200，设备码和官方 HTTPS 授权链接正常返回。未记录实际 AppKey 或设备码；未使用用户 SecretKey，也未代替用户登录。该结果不能代表 Token 交换或文件接口通过。

## 发布门槛

`0.1.2` 已提供本地候选安装包供用户进行真实授权和安装验收。正式创建该版本的 GitHub Release 前，应完成至少一次真实安装、授权与手动文件往返检查；无法访问用户自己的应用时不代替用户签署验收。

0.1.1 的发布内容保持不变。后续发布附带三个插件文件、安装 ZIP、SHA256SUMS 和明确的验证边界。
