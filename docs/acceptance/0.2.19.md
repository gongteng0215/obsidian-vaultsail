# 0.2.19 双端与自动同步验收

本轮不更改云端格式、配对、授权、删除开关、文件大小或并发上限。
自动化结果与原生设备结果分别记录；模拟 iPad 不作为原生 iPad 通过。

## 自动化回归

| 场景 | 验证点 | 证据 |
| --- | --- | --- |
| 文件/目录预检任一失败 | 两项检查都返回后才释放调用者，不进入文件传输或推进基线 | `test/preflight.test.ts`、`test/sync.test.ts` |
| 预检期间继续编辑、请求远端检查 | 队列保持运行，重载后保留待办与阻断原因；手动重试后处理新修改 | `test/queue.test.ts` |
| 另一设备在预检期间发布修改 | 保留两条父版本分支，结束时发现新操作，冲突处理保留双方内容 | `test/sync.test.ts` |
| 自动轮询发现远端修改 | 使用已验证初始清单，不重复初始扫描，写入后仍完整复查 | `test/sync.test.ts` |
| 暂停、取消、失败分页 | 不发布笔记；失败页不留缓存，后续请求重新查询 | `test/preflight.test.ts`、既有扫描测试 |
| 同时读取相同分页 | 仅合并在途请求，返回独立对象；后续轮次必须重新请求 | `test/preflight.test.ts` |
| 写入响应丢失、同时有旧普通列表 | 写入结果核验绕过普通列表合并，不能据旧列表再次提交 | `test/preflight.test.ts`、既有恢复测试 |
| 用户设置并发为 1 | 并行预检依然只有 1 个实际请求，不突破共享预算 | `test/preflight.test.ts` |
| 休眠/前后台与重载 | 保留显式暂停、待办和共享原生请求额度，过期响应不推进新会话 | 既有 queue、request-pool、UI、auth 与 recovery 测试 |
| 空目录、删除、并发改名与冲突 | 保留既有安全语义与恢复点 | 既有 directories、sync 与 UI 测试 |
| 数字性能报告 | 排除路径、任务时间、账号范围、任意响应和凭据字段 | `test/local-performance-report.test.ts` |

这里的“检查结束”指对应检查 Promise 已返回。若原生请求超时后仍在系统中执行，其共享请求额度继续保留到原生请求实际结束；不会因前端结束而提前放宽并发。
