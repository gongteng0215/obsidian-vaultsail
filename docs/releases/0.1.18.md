# VaultSail 0.1.18 测试版

> 2026-10-15 更正：本记录中关于“测试版不会更新社区安装版本”的判断不成立。社区安装依据仓库 manifest.json 的版本选择包，GitHub prerelease/Latest 标记不能单独隔离；请以实际安装版本和最新发布说明为准。

修复账号导入、插件重载和文件请求等待中的稳定性问题，供 Windows 与 iPad 验证；社区条目继续保留 0.1.17，待真实设备验证后再更新。

- 导入保存与后续插件实例的配置读取按顺序执行。重载时先完成旧实例的回滚，再读取连接；回滚失败时保留两份凭据，避免清掉仍被保存配置引用的连接。
- 导入验证期间可取消，原连接保留。进入本机保存阶段后显示「正在保存，请稍候」，暂时禁用取消和关闭，完成或失败后恢复操作。
- 元数据请求超时为 30 秒，分片上传和内容下载为 120 秒。读取与普通网络错误最多自动重试三次；断开连接或卸载会停止等待迟到的请求结果。暂停等待当前请求结束，未完成任务保留恢复记录。
- 写入超时先核验远端结果。内容一致则接受已完成的写入；结果仍不明时停止，不自动重复提交，之后可核验并恢复。Obsidian 原生请求无法由插件撤回，停止等待不等于撤销服务端写入。
- 同步完成保留上传、下载及冲突处理结果；失败保留具体错误，不再被「操作完成」覆盖。

105 项自动化测试、类型检查、构建和 ZIP 校验通过。新增覆盖跨模块重载排队、保存失败回滚、回滚失败保留凭据、新配置不被旧回滚覆盖、导入取消、保存阶段关闭保护、请求超时与迟到结果、写入超时核验、限流等待可暂停、暂停后恢复不重复发布。真实百度账号与 iPad 前后台行为仍待用户设备验证。

最低 Obsidian 1.11.4；单文件 20 MiB、并发 1；旧配对码在原 24 小时有效期内继续兼容，无需因升级重新授权。默认仅迁移账号，不绑定导出端云端库；云端笔记内容未端到端加密。
