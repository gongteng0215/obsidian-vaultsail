# 0.2.13 · 常规删除设置 / Standard deletion setting

本地预览，最低 Obsidian 1.11.4，尚未发布社区。

- 「传输与恢复」直接显示「同步删除」，默认关闭。取消旧的两层开关，开启仍需确认其对手动及自动同步的影响。
- 旧配置按原来实际生效的删除状态迁移，原先关闭的不会因升级开启。旧门槛不再进入运行配置、诊断和后续保存。
- 开启后，在已开启自动同步的库中加入一次完整检查；自动同步关闭时不自行启动任务。关闭删除无需再次确认。
- 设置保存失败时恢复原值和界面；运行中不允许切换，旧连接的确认弹窗不能用于新连接。
- 去掉设置界面中的实验入口和相关文案；保留已有「先看同步清单」，诊断折叠区改名「诊断与报告」。
- 删除仍使用可信基线与版本化删除记录，保留恢复数据，不永久清理云端内容。授权、绑定、其他用户设置与云端格式不变。

215 项自动化测试、类型检查、生产构建与三文件 ZIP 校验通过。覆盖新旧配置迁移、默认关闭、确认/取消、保存失败、任务占用、连接变更和实际设置入口；删除引擎原有安全回归继续保留。已备份并安装到本机「笔记」和「测试」，安装文件 Hash 与包一致，配置文件 Hash 未变；记录保存于 dist/installation-0.2.13.json。界面分类变更不代表 Windows/iPad 长期验收已全部完成。

Local preview requiring Obsidian 1.11.4; not published to the community.

- **同步删除** is directly available under **传输与恢复**, off by default. The old two-toggle gate is removed; enabling still confirms its effect on manual and automatic sync.
- Migration preserves the effective legacy setting and drops the obsolete gate from runtime settings, diagnostics and later saves.
- Enabling queues a full check only when automatic sync is already enabled. Disabling needs no extra confirmation.
- Failed saves restore the previous value; busy tasks and stale connection confirmations cannot change the setting.
- Experiment controls/labels are removed from settings. Existing sync preview remains available; diagnostics are grouped under **诊断与报告**.
- Trusted baselines, versioned deletions and recovery data remain in place. Cloud objects are not permanently purged; authorization, bindings and other preferences are unchanged.

All 215 tests, type checking, production build and three-file ZIP verification passed. Coverage includes migration, default-off behavior, confirmation/cancellation, save failure, busy tasks, connection changes and the actual settings entry. Both local installations were backed up and updated; asset hashes match the package and configuration hashes are unchanged. Native Windows/iPad long-term acceptance remains separate.
