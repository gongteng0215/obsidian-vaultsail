# 0.2.11 · 自动同步提醒 / Automatic sync notifications

本地预览，最低 Obsidian 1.11.4。保留现有自动同步开关、检查间隔、绑定与凭据，无云端格式变更，尚未发布社区。

- 自动检查无变化时不弹通知。实际上传、下载、自动合并或删除完成后，显示数量摘要，持续 4 秒。
- 冲突保留双方、跳过未传输项明确提醒，持续 12 秒，并指向待解决冲突或传输中心。
- 没有实际传输、冲突与跳过数量相同的提醒，5 分钟内不重复。提醒限制仅影响通知，不改变传输、版本或重试规则。
- 网络异常和限流说明将自动重试；授权、权限、配置与其他停止原因给出处理入口。相同失败类别在一次连续故障期间只提醒一次，成功核验后重新允许提醒。
- 失败后云朵显示警示色，悬停可看原因。下一次任务运行时仍显示运行状态；成功核验、手动暂停或连接变更后清除旧失败警示。
- 自动通知替换上一条自动通知，避免多条堆叠。手动点击与手动完成提示保留。手动暂停、取消、任务占用和变化重规划不弹失败提示。
- 提醒只包含固定说明和数量，不复制原始异常、请求地址、文件名或凭据。提醒去重状态仅保存在本次插件会话内，重启后重新计算。

213 项自动化测试通过，类型检查、生产构建和三文件 ZIP 校验通过。验证覆盖通知分类、无变化静默、重复限制、隐私过滤，以及实际插件队列到历史记录与通知的链路。已备份并安装到本机「笔记」和「测试」，安装文件 Hash 与包一致，配置文件 Hash 未变；记录保存在 dist/installation-0.2.11.json。模拟引擎结果与真实百度传输分开验收；原生 Windows 主题、iPad 前后台与真实同步通知仍需设备确认。

Local preview requiring Obsidian 1.11.4. Existing automatic-sync settings, bindings, credentials and cloud formats are preserved; not published to the community.

- No-change checks stay quiet. Actual transfers, automatic merges and deletions show a four-second count summary.
- Preserved conflicts and skipped files receive actionable twelve-second warnings. Repeated identical counts without actual transfers are limited to once per five minutes.
- Network/rate failures explain automatic retry; authorization, permission, configuration and other stopped tasks explain where to inspect the problem. Each failure category is announced once per continuous incident, reset by verified success.
- The cloud ribbon shows a warning color after failure. Running tasks keep their running state; verified recovery, explicit pause or connection changes clear stale failure warnings.
- Automatic toasts replace previous automatic toasts. Manual feedback is preserved. Pause, cancellation, scheduling contention and replan do not trigger failure notifications.
- Notifications use fixed text and counts without raw exceptions, request URLs, filenames or credentials. Deduplication is session-local and never changes queue or sync decisions.

All 213 tests, type checking, production build and three-file ZIP verification passed. Coverage exercises classification, quiet checks, duplicate limits, privacy and the actual plugin queue/history/notification path with controlled engine outcomes. Both local vault installations were backed up and updated; asset hashes match and configuration hashes are unchanged. Native Windows/iPad and live Baidu acceptance remain separate.
