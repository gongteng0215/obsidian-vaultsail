# 0.2.19 本地预览：并行预检与云文件列表缓存

日期：2026-10-20。公开发布仍为 0.2.18，本预览尚未提交社区。

## 本次改动

- 同步前的文件历史与目录预检并行执行，两项都成功后才进入文件传输。复用本轮已经完成的文件扫描，第二轮检查及写入后复查仍读远端。
- 上传、下载与双向预览也并行读取两类清单。任一检查失败后等待另一项返回，避免界面结束后旧检查仍改动缓存。
- 同一连接内，同时发生的相同目录/游标请求只发送一次。每个调用者拿到独立对象；不保存已完成的分页或“目录不存在”结果供下一轮使用。
- 结果未知的写入、恢复核验使用独立的新请求，绕过普通分页合并。
- 云文件列表复用按账号、应用、库、连接代次和并发设置隔离的读取器，保留内存缓存。每次打开仍完整检查远端设备目录与分页，发现新版本；不靠缓存假定远端没有变化。
- 新增 `scripts/report-local-performance.mjs`，仅从本机历史提取经过白名单验证的计数和耗时，汇总最近 30 条记录。报告没有目录、文件名、任务时间、设备/账号范围、响应正文、请求地址或凭据，不联网。

## 真实现场与模拟结果分别记录

本机保存的 30 条 0.2.18 桌面任务均完成且没有文件传输：每轮 8 次请求、58/58 条文件版本缓存命中、历史正文读取和缓存写入均为 0。任务耗时中位数 **2392 ms**、P95 **3552 ms**；云端阶段中位数 **1998 ms**。这些记录确认上一轮缓存修复生效，不能代替 0.2.19 的原生验证，也不能与早期不同数据集直接计算真实提速比例。

本轮以发布提交 `bd6a1cea6b71fd0b1606c5926bb5011614f45307` 为 0.2.18 基线，覆盖 7、100、1000 篇固定内容笔记、两个文件设备目录、约每 8 篇一条空目录记录。新旧实现于同一进程交替执行，每组 10 次，每请求模拟等待 15 ms。全部请求仍经过模拟百度响应及实际解析/校验逻辑，不连接用户账号。

首次打开列表仍有计时波动，没有稳定提速结论；本轮对它主要减少一个重复请求。再次打开通过复用内存读取器减少库元数据下载。1000 文件早期分进程低延迟结果曾出现明显波动，最终以上述同进程交替运行结果为准，不据单次最短耗时宣称提速。

最终数字见 [对比报告](../benchmarks/0.2.19-preflight.json)。模拟数据包含夹具与本机运行开销，不能承诺真实百度固定秒数或固定提速比例；目录请求只有实际重叠时才合并。

复现：

```text
node --experimental-strip-types scripts/benchmark-sync-preflight.mjs compare 7 10 15
node --experimental-strip-types scripts/benchmark-sync-preflight.mjs compare 100 10 15
node --experimental-strip-types scripts/benchmark-sync-preflight.mjs compare 1000 10 15
```

分别覆盖冷读取、再次无变化、重启、单文件本地修改、另一设备单文件修改、首次及再次打开云文件列表。无变化任务不读取历史正文、不重写未变化缓存；单文件改动保留必要发布、内容校验与结束前复查。

## 验证与兼容

**271 项自动化测试、类型检查通过。** 新增覆盖失败预检等待、失败前不传输、在途分页合并、独立对象、失效后重查、共享请求上限为 1、写入响应丢失核验、检查期间竞争修改、自动发现远端修改、暂停、队列重载保留待办、云列表缓存隔离与数字报告脱敏。保留既有删除、冲突、空目录、100 次中断恢复和界面状态回归。

原生请求超时但尚未实际结束时，继续占用共享请求额度；不会因检查 Promise 返回而提前释放系统中仍运行的请求。真实网络限流行为未由模拟结果代替。

最低 Obsidian 1.11.4；不改云端格式、配对码、授权或库绑定。文件并发默认 8（1–32）；电脑分片并发默认 2（1–4），移动端 1；电脑单文件最高 512 MiB、移动端 20 MiB，均保留现有选择。删除默认关闭。无需重新授权或重新导出仍有效的配对码。

[双端及自动同步验收清单](../acceptance/0.2.19.md) 已单独列出原生待测项。真实 0.2.19 百度耗时、Windows/iPad 互传与长期刷新仍待加载本地预览后验证。

## English

This local preview overlaps read-only file and directory preflight checks, reuses the verified initial inventory, and coalesces only identical in-flight listing pages. Checks settle before transfer or task release. Unknown-write verification bypasses ordinary page sharing. Reopening the cloud browser preserves connection-scoped in-memory caches while still listing every remote device and page. Account, vault, generation or concurrency changes invalidate the reader.

271 automated tests and type checks passed. A new offline report tool exports only validated numeric performance aggregates. The baseline's 30 existing desktop tasks confirm cache hits with no historical body reads; these are not live measurements of the new implementation. Synthetic comparisons use 7/100/1000 notes, 10 paired rounds and a 15 ms request delay. Native iPad, live Baidu throughput and long-term multi-device acceptance remain pending. Authorization, pairing, storage format and user defaults remain compatible.
