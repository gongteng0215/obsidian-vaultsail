# VaultSail 0.1.13

补齐 Obsidian 社区审核所需的英文说明，并明确文件枚举、剪贴板使用和网络服务。同步及加密配对行为与 0.1.12 相同。

已提交并发布社区条目：https://community.obsidian.md/plugins/vaultsail 。自动审核和目录可安装状态以官方页面为准，当前不宣称已经通过审核。

最低 Obsidian 1.11.4。单文件 20 MiB，并发 1，手动触发，删除同步默认关闭。配对配置加密，云端笔记尚未端到端加密。真实 iPad 导入、真实大规模跨端及长期双设备令牌续期仍待实机验证。

86 项自动化测试、构建及安装包检查通过。下载 ZIP 或 main.js、manifest.json、styles.css，放入知识库配置目录的 plugins/vaultsail/，然后关闭再启用插件。
