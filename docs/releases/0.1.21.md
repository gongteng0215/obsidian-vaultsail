# VaultSail 0.1.21 测试版

并发配置从 1–4 路下拉选项改为可自行输入的数字框，支持 1–32 之间的整数，未配置或配置无效时默认 8。输入后点击「保存并发数」生效，输入过程中不保存中间值，并提供「恢复默认 8」按钮。

已有合法保存值会保留；升级后如仍显示原来的 3 或 4，可点击「恢复默认 8」。设置独立保存在当前 Vault，修改不解除账号/云端库绑定、不丢弃预览，导入账号连接也保留当前并发选择。上传、下载和历史读取使用相同配置，大附件批次预算与本地串行提交保护不变。

127 项自动化测试、类型检查、构建和 ZIP 校验通过。新增验证默认 8 路的实际上传、下载及历史读取，所有文件 Hash 一致；自定义 12 路实际工作，数字输入/显式保存、非法小数拒绝、恢复默认及账号导入保留设置均有回归覆盖。真实百度限流和 iPad 内存仍需设备验证，较高配置不保证带宽线性提升。

最低 Obsidian 1.11.4，单文件 20 MiB，云端格式与旧有效配对码兼容。仅发布 GitHub 测试版，社区更新继续等待真实设备验收。
