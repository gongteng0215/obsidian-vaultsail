# 0.2.5 — 本地布局修复版 / Local layout fix

当前仅供本机验证，尚未发布到 GitHub Releases 或社区。
This build is for local verification and has not been published to GitHub Releases or the community directory.

- 修复点击右上角放大后，Obsidian 设置页的居中边距挤压插件内容的问题。插件自己的内容宽度与边距现在保持一致。
- 调整窄窗口中的页签、表单、按钮和同步记录筛选控件，允许收缩与换行。
- 传输页的单文件上限说明跟随当前设备和实际配置显示。
- 修复不更改账号、密钥、云端库绑定、笔记内容或同步策略；升级不需要重新导出配置。

- Fix host settings centering squeezing plugin content when the window is maximized.
- Allow tabs, form controls, buttons, and history filters to shrink and wrap in narrow windows.
- Show the effective per-file size limit for the current device and configuration.
- Account credentials, vault bindings, notes, and sync behavior are preserved; configuration does not need to be exported again.
