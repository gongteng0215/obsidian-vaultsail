# VaultSail 0.1.17

分离账号连接迁移与云端库配对。默认只加密导出应用配置和百度授权，不包含当前云端库 ID 或名称；源 Vault 尚未绑定云端库时也可导出。导入默认只连接账号，之后由当前 Vault 创建或选择自己的云端库，不自动传输笔记。

两台设备需要同步同一个库时，在导出端明确开启「同时导出当前云端库」，并在导入端开启「绑定配对码中的同一个云端库」。旧加密码和 JSON 配置仍可读取，但其中的目标不会自动绑定；账号专用码需由 0.1.17 或更新版本导入。导入前明确提示将替换账号连接、清除当前云端目标设置，本地笔记保留，删除传播关闭。

92 项自动化测试、类型检查、构建及 ZIP 校验通过。模拟覆盖已绑定/未绑定源 Vault 导出、旧码默认不绑定、明确同库配对、独立建库上传不修改源库、重复导入、回滚及重启恢复。真实 iPad 本次交互仍需设备验证。

最低 Obsidian 1.11.4；单文件 20 MiB、并发 1；配对码 24 小时内可导入；云端笔记未端到端加密。社区自动检查与应用内目录同步分别以官方结果为准。
