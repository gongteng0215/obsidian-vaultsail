# 0.2.23 本地预览 / Local preview

日期 / Date: 2026-10-20。

## 现场原因与范围 / Findings and scope

官方后台的历史 **0.2.18 Failed** 有两处直接设置静态样式的阻断错误（`src/ui/diagnostics.ts:15,25`），并另报发布主文件无法从源码逐字节复现的警告。0.2.22 已修复这两类问题，官方结果为 Completed、构建一致性 Pass，但仍有 159 条源码/CSS 警告及 7 项其他提示。不能把 Caution 的全部提示都称为失败或安全漏洞。

The historical 0.2.18 failure contained two blocking inline-style errors and a separate build mismatch warning. Both were corrected in 0.2.22, whose official review is Completed with reproducible-build verification passing. This preview addresses the remaining code compatibility findings; branch-preview results below are distinct from a release review.

## 修复 / Changes

- 使用官方 `eslint-plugin-obsidianmd` 推荐检查，覆盖全部运行时 TypeScript；`npm run lint` 要求 0 错误、0 警告，并接入 CI。英文品牌、协议前缀和标准单位有明确大小写配置；未关闭审核规则、未排除运行时代码。
- 移除无效类型断言；校验本机成功摘要、权限结果和诊断条目，只向诊断展示固定字段。存储适配器改为有类型的调用包装，保留方法接收者、参数、调用时读取与原异常原因链。
- 使用浏览器所属的定时器和共享注册表；原有 Symbol 键及按 App 隔离的 WeakMap 保留，插件重载互斥继续有效。Node 测试和离线工具提供显式浏览器宿主。
- DOM 改用 Obsidian 的 span/SVG 创建方法；静态样式继续位于 CSS。移除 5 处 `!important`，以选择器优先级保证隐藏区域及选中标签样式。
- 本地删除使用 `FileManager.trashFile()` 尊重用户回收站偏好，删除前的内容核验及恢复副本继续保留。
- 补齐新版设置定义与搜索别名，以自定义渲染保留紧凑工作台；1.11.4 继续使用 `display()`。进度局部刷新、草稿与滚动位置不变。
- 核心逻辑不再假定配置目录名称；本机调用继续传入 `Vault.configDir`，隐藏目录和内部目录仍强制排除。
- 使用非弃用 SHA-256 入口；无可信类型的远端文件指纹回退为重新读取。分片失败保留 Error 原因链，阻止其他分片继续发布。
- 生产构建统一主清单与样式文件的换行格式，避免 Windows 和 CI 的三份插件资产出现字节差异；新增 CRLF/LF 构建对照回归。

Official recommended lint rules now gate CI. Changes include typed and validated local records, browser-owned timers and DOM helpers, preferred trash handling with verified recovery copies, searchable settings with the legacy UI fallback, and CSS specificity fixes. The cloud format, pairing format, minimum Obsidian version, concurrency, user configuration and connection remain unchanged.
