# 0.2.17 本地预览 / Local preview

- 应用入口直接打开 `https://pan.baidu.com/union/console/applist`，按钮改为“打开我的应用”。
- 设置页新增紧凑、可折叠的六步引导：登录控制台、创建应用、从“编辑 → 应用凭证”获取两项密钥、分别保存、连接授权、验证并绑定云端库。
- 提供应用名称与描述示例，区分 AppKey/SecretKey 与 AppID/SignKey。未配置时默认展开，已有配置时默认折叠；刷新保留用户的展开状态。
- 更新中英文首次配置说明；已有应用无需重建。现有授权流程、密钥、云端库绑定和同步设置不变。

Application setup now links directly to Baidu Netdisk's application list. A compact six-step guide explains application creation, credential location, separate save controls, account authorization and vault setup. It opens by default when application configuration is missing and preserves disclosure state during refresh. Existing applications, credentials and sync behavior are preserved.

应用列表与凭证字段按用户提供的官方页面截图核对；自动抓取控制台不可用，未代用户创建应用或读取应用密钥。253 项自动化测试通过，界面验证覆盖入口地址、引导内容、首次使用默认展开与刷新保留展开状态；类型检查、构建及安装包验证作为本机交付检查。真实百度创建应用和新用户首轮配置仍待实际验收。本次仅本机预览，尚未发布社区。
