# 0.2.6 — 传输中心本地预览 / Local transfer center preview

本版先在本机验证，尚未发布社区。最低 Obsidian 1.11.4。配置、授权、绑定及云端格式保持兼容。
This is a local preview, not a community release. Requires Obsidian 1.11.4+. Configuration, authorization, bindings and the cloud format remain compatible.

## 使用 / Usage

- 左侧工具栏点击「VaultSail：传输中心」，或命令面板运行「VaultSail：打开传输中心」。设置页也提供入口。
- 电脑默认打开右侧面板，可通过 Obsidian 移动到其他位置；移动端使用完整标签页。同一 Vault 重复打开会复用面板。
- 本轮文件包括等待、处理中、已完成及需处理项，支持搜索和筛选；每页 50 条，沿用本机历史最近 30 次、每次 1000 条 / 2 MiB 上限。记录截断时明确提示计数不完整。
- 每 500 毫秒更新可见进度，保留详情展开与搜索输入。显示实际确认字节、估算速度、上传阶段剩余时间、等待分片确认时间及阶段耗时。回读校验和保存版本完成前不算成功。
- 可暂停整个任务、核验恢复后继续同步、打开历史记录。关闭面板不停止同步。重启后保留文件结果；速度和分阶段观察值仅在当前会话内有效。

Open **VaultSail: 打开传输中心** from the command palette or use the new ribbon/settings entry. Desktop opens a reusable side panel; mobile uses a full tab. Search and filter pending, active, completed and attention rows, with 50 rows per page and the existing local history limits. Updates preserve search input and expanded details. Confirmed bytes, estimated speed/upload ETA, acknowledgement waits and observed stage durations are separate from verified completion. Closing the panel does not stop sync. Historical outcomes persist; live measurements do not survive reload.

## 上传准备优化 / Preparation improvements

- 在传输前重新核验内容时复用同一次 SHA-256 结果作为版本摘要，减少一次整文件摘要计算；后续独立校验保留。
- 同一次对象上传调用内，重试复用已计算的分片 MD5 列表；重试会话仍重置确认计数，不将重传累加为总进度。
- 新增「本次请求实际确认字节」，服务端已有分片和已存在对象不会被当作网络速度；共享内容的观察者不会重复增加汇总速度。

Reuse the already-computed source SHA-256 during pre-transfer revision preparation, and reuse block MD5s within upload-call retries. Independent content/recovery/readback verification remains. Per-attempt acknowledged request payload excludes server-reused parts and existing objects; shared content is counted once in aggregate speed.

## 验证与边界 / Validation and limits

- 189 项自动化测试通过，覆盖原有同步链路及新增速度去重、重试重置、终态计时冻结、等待提示、稳定 DOM、搜索分页、跨库清空、桌面视图复用与移动端标签页路由；类型检查、构建与安装包检查通过。
- 独立 64 MiB 合成数据、5 轮源文件 SHA-256 准备对比：两次计算中位数 469.5 ms，复用一次结果为 234.9 ms。这仅是被优化的准备步骤，不代表整体上传或真实网络提速倍数。
- 使用已安装 Obsidian 样式与真实面板代码进行浏览器布局验证；界面样例为合成数据，不访问真实网盘或笔记。
- 不将预览与模拟测试视为 Windows/iPad 真机或真实百度吞吐验收。需重新启用插件，在本机确认面板、暂停恢复和真实传输显示。
- 文件并发仍默认 8、范围 1–32；大文件仍一次一个、单文件内分片串行。电脑上限 512 MiB，移动端 20 MiB，仍为整文件缓冲。
- 本版未加入分片并发、流式 I/O、跨重启分片续传或关闭完整性验证。后续性能阶段分别验证后交付，不承诺固定网速提升。

Automated checks cover existing sync behavior plus throughput deduplication, retry resets, terminal timing, wait indicators, stable DOM, search/pagination, context isolation, native view routing and reuse. Browser previews use synthetic data with the installed host stylesheet, without accounts or notes. Native Windows/iPad and real Baidu throughput validation remain separate acceptance steps. Existing file concurrency, whole-buffer limits, sequential per-file chunks and integrity protections remain. Chunk parallelism, streaming and restartable slice checkpoints are later stages.
