# VaultSail 0.1.19 测试版

> 2026-10-15 更正：本记录中关于“测试版不会更新社区安装版本”的判断不成立。社区安装依据仓库 manifest.json 的版本选择包，GitHub prerelease/Latest 标记不能单独隔离；请以实际安装版本和最新发布说明为准。

修复同步进度看起来不动、失败后进度区域缺少原因，以及上方「操作完成」与下方失败状态并存的问题。

- 从检查百度连接、验证云端库开始显示本次任务，立即替换旧进度。活动任务每 500 毫秒更新视图，耗时按秒变化；等待新进度超过两秒时显示已等待时间。文件数与已校验字节只按真实完成量更新。
- 只更新状态文字和进度条，保留当前页签、滚动位置和未保存输入。设置页临时失效不会打断其他进度订阅者或计时器。
- 失败和暂停明确显示停止状态、安全错误原因及恢复/重新同步入口，计时停在实际结束时间。「操作完成」不再掩盖上次传输失败。
- 新任务清除上次失败内容，连接检查阶段也可请求暂停；暂停等待当前请求结束。退出插件清理刷新计时器。

111 项自动化测试、类型检查、构建及 ZIP 校验通过。包含实际定时器驱动设置界面的验证：等待期间耗时更新、统计不虚增、DOM 与未保存输入保留、失败计时冻结、错误提示及恢复按钮、新任务清除旧状态、异常视图隔离和连接检查暂停。真实百度账号及 iPad 前后台行为仍需用户设备验证。

最低 Obsidian 1.11.4；单文件 20 MiB、并发 1；旧有效配对码继续兼容。仅发布 GitHub 测试版，社区更新仍等待真实设备验收。
