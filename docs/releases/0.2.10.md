# 0.2.10 · 同步点击即时反馈 / Immediate sync feedback

本地预览，最低 Obsidian 1.11.4。包含 0.2.9 扫描优化，尚未发布社区。

- 点击云朵、同步命令或界面的开始同步，立即显示已接收/排队提示。
- 库尚未加载、网络离线或应用在后台时，明确显示等待原因。
- 云朵在排队时高亮，运行时轻微闪动；悬停显示队列或当前操作状态。尊重系统减少动态效果设置。
- 同步中重复点击立即提示已加入队列，多次点击仍合并为一次后续检查，不并行启动额外同步任务。
- 完成、暂停或失败后清除运行状态；自动检查和内部续接不新增点击提示。
- 不改授权、绑定、云端格式或用户的同步设置。

交互回归使用实际插件入口和云朵点击回调，阻塞任务以核验提示先于完成出现，并覆盖启动等待、重复点击、后续任务合并、静默续接和失败状态复位。207 项自动化测试、类型检查、生产构建及三个插件文件的 ZIP 校验通过。已备份并覆盖安装到本机「笔记」和「测试」，安装文件 Hash 与包一致，配置文件 Hash 未变。本机交付记录保存于 dist。原生 Windows 主题下的图标效果和真实百度同步仍需用户安装验收；模拟结果不代表 iPad 真机验证。

Local preview requiring Obsidian 1.11.4. Includes the 0.2.9 scan improvements; not published to the community.

- Sync clicks receive an immediate acknowledgement, with explicit startup, offline or background waiting messages.
- The cloud ribbon icon highlights while queued and pulses while running; its tooltip reflects current activity. Reduced-motion preferences disable pulsing.
- Repeated clicks during a task are acknowledged and coalesced into one follow-up check. Sync tasks remain serialized.
- Completion, pause and failure clear the running indicator. Automatic checks and internal continuations do not add click notifications.
- Authorization, bindings, cloud formats and user settings are preserved.

Integration coverage invokes the actual plugin ribbon callback with a gated task to verify feedback before completion, including startup waiting, duplicate clicks, follow-up coalescing, quiet continuation and failure cleanup. All 207 tests, type checking, production build and three-file ZIP verification passed. Both local vault installations were backed up and updated; asset hashes match the package and configuration hashes are unchanged. Automated checks and packaging do not replace native Windows/iPad or live Baidu acceptance.
