# 0.2.8 — 紧凑布局本地预览 / Compact layout preview

本地测试版，尚未发布社区。最低 Obsidian 1.11.4，包含 0.2.7 上传优化。
Local preview, not a community release. Requires Obsidian 1.11.4+ and includes the 0.2.7 upload improvements.

## 调整

- 传输中心压缩顶部摘要、卡片边距和文件行；目录、操作与大小合并排列，筛选和搜索在空间允许时共用一行。
- 成功文件显示结果，不再保留整行上传进度条；当前传输与待核验项保留进度。文件名、错误提示、搜索筛选、分页及可展开详情仍然可用。
- 设置页简化品牌展示，收紧状态区、进度区和导航间距；进度入口与折叠详情并排。较宽卡片的说明和操作并排，较窄卡片自动上下排列。
- 保留正文大小，长名称与按钮可换行。触摸输入保留至少 44 px 的主要按钮和输入区域。
- 不修改同步、账号、授权、库绑定或云端格式；安装时仅替换插件的三个文件。

## 验证

使用实际界面代码、已安装 Obsidian 样式和合成数据对比：860 px 面板宽度、默认字号、从面板顶部计算 650 px 可用高度，传输中心完整文件行从 **1 条增加到 5 条**；普通文件行约 **164 px → 79 px**，顶部至列表约 **367 px → 190 px**。这是固定样例的浏览器布局测量，不代表所有主题和真实设备都得到相同数值。

200 项自动化测试、类型检查、构建与安装包检查通过。布局检查覆盖 300 px 窄面板、最大化宽度、大字号与缩放、深浅主题、展开详情和搜索筛选。布局预览也修正了字号变量被宿主主题覆盖的问题，按实际计算字号确认放大生效。原生 Obsidian/iPad 视觉体验仍需用户确认。

重新启用插件即可使用。若传输中心已打开，可关闭后重新打开以载入新的列表结构。

## English

The transfer center uses smaller gaps, compact metadata rows and a shared filter/search toolbar when space permits. Completed files retain their verified result without an upload meter. Progress, errors, full file names and expandable details remain available.

Settings have a shorter brand/status/progress area. Wide cards place descriptions and controls side by side; narrow cards stack them. Body text sizes remain unchanged, and coarse-pointer controls keep 44 px minimum touch targets. Sync, credentials, bindings and the cloud format are unchanged.

With synthetic data and the installed host stylesheet, an 860 px panel fits five complete file rows within the first 650 px instead of one; ordinary rows decrease from about 164 to 79 px. All 200 automated tests and build/package checks pass. These are browser measurements for this fixture, not a guarantee across themes or native devices. Re-enable the plugin and reopen an existing transfer center tab after installation.
