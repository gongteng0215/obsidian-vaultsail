# VaultSail 0.2.2：本机同步记录（本地预览）

日期：2026-10-16。基于 0.2.1 的本地试用更新，来自 `codex/sync-history`，不推进社区默认分支版本，不更改云端格式或恢复日志。

## 查看方式

更新后关闭再启用 VaultSail，确认版本 0.2.2。打开「传输与恢复 → 同步记录 → 查看同步记录」，或从命令面板执行「VaultSail：查看同步记录」。任务运行期间也可打开。

- 下拉选择本设备、当前连接及云端库的最近任务，显示时间、手动/自动/单向/恢复/冲突处理与结果。
- 每个文件显示路径、动作、大小、更新时间、处理耗时、状态和固定的安全原因。
- 状态区分等待、处理中、成功、跳过、无变化、冲突、失败、暂停、未确认与未执行；完成校验和状态提交后才显示成功。
- 可按路径搜索、按动作或结果筛选，每页 50 条。「最新任务」跟随新任务；手动选择历史任务后不会因实时刷新跳走。
- 上传下载、删除记录、自动合并、冲突保留/解决和未完成任务恢复均产生相应条目。只查看预览不算执行记录。
- 手动或自动无变化检查可能只有任务记录或无变化条目，不伪造文件传输。历史从本版启用后开始记录，不补造旧任务的文件列表。

## 保存与边界

保留最近 30 次任务，每次最多 1000 条或 2 MiB。达到容量会明确标记截断，条目统计不代表完整任务；记录轮替仅清理本插件拥有的显示历史文件，不清理笔记、暂存或恢复日志。

位置：`.vaultsail-state/<本设备ID>/history/<连接指纹>/`。路径只用于本机显示，不记录正文、令牌、SecretKey、URL、请求体或原始异常。此目录已被 VaultSail 排除，不进入配对和脱敏诊断；诊断仍不包含文件名。同步记录本身含私人文件路径，不应作为脱敏报告分享。

文件记录随执行更新，约每秒批量落盘，结束时再保存；重启可读已保存内容。关闭或崩溃前未落盘的最新变化可能缺失；重启发现未结束任务时显示中断、未确认或未执行，不自动视为成功。日志不是恢复依据，实际结果仍由同步引擎核验。

记录损坏或保存失败会在记录窗口显示提示，保留当前会话结果，不让显示记录失败冒充笔记传输失败。失败条目只显示白名单错误类别。切换账号、应用、目录、云端库或设备后，读取各自范围，旧记录不混入新连接。
