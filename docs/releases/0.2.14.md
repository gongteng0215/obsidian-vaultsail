# 0.2.14 · 后台更新不打断操作 / Stable background UI updates

本地预览，最低 Obsidian 1.11.4，尚未发布社区。不改变授权、绑定、删除开关、同步队列、云端格式或配对格式。

## 原因与改动

网络请求已经是异步。主要问题是请求开始/结束和状态变化后，设置页调用 `empty()` 重建整页；同步记录定时清空并创建列表；新任务替换正在阅读的传输列表。这些会丢失滚动、焦点、草稿或展开状态。修复不靠延时强行滚回旧位置。

| 已排查位置 | 本轮处理 |
| --- | --- |
| 设置页：任务开始/结束、队列与进度刷新 | busy/status/进度变化只更新现有节点与控件，不重建表单。文本草稿仍可编辑，提交按钮和会直接改配置的开关在任务中禁用。 |
| 设置页：授权、绑定与配置结构变化 | 仅结构依据变化时重建，在提交界面更新的当下保留滚动、焦点、光标、展开状态及未保存文本；不同连接不继承旧凭据草稿。 |
| 设置保存响应 | 明确提交/恢复默认值可以更新对应字段；等待保存期间用户继续编辑的更新草稿保留。并发设置保存串行互斥，失败恢复原配置。 |
| 设置与清单内的上传进度 | 按文件路径保留上传行，只更新文字和进度条，不因分片确认清空列表。 |
| 同步记录 | 按任务/文件 ID 更新行和任务选项，不因心跳重建整表。后台新增任务不自动替换所选任务，可点击「最新任务」切换。 |
| 传输中心 | 保留原有局部更新；正在滚动、翻页、搜索或展开详情时，新任务提示「查看最新任务」，当前列表保持可读和可筛选。开始同步或明确查看最新任务可切换。 |
| 云文件树 | 搜索、展开/折叠提交时保留滚动和焦点；目录展开选择仍由树组件负责，不被滚动保护覆盖。 |
| 冲突列表/编辑器 | 核验时保留旧列表；只接收最新请求，关闭后忽略返回。旧列表的详情响应不再打开过期编辑器；已有编辑草稿和提交保护保留。 |
| 云端库绑定、恢复点、云文件弹窗 | 关闭/离开或连接失效后，不追加迟到的内容或打开旧弹窗。 |
| 配对导入/导出与传输清单 | 核对现有 generation、关闭清理和取消订阅；没有定时整页重建。实际绑定完成后的结果页替换、主动筛选/翻页及连接切换仍是明确的界面变化。 |

滚动状态在真正修改 DOM 前读取，同步完成恢复，不在网络请求开始时保存后延时回写，避免覆盖用户后来发生的滚动。内容变短时浏览器仍受可滚动范围限制；不添加大块空白伪造滚动高度。

## 验证

- 217 项自动化测试通过：任务中保留节点/草稿、连续结构更新、保存等待期间继续输入、失败恢复、历史行身份、后台任务阅读保留、最新请求优先和关闭后的迟到响应。
- 类型检查、生产构建与三文件 ZIP 校验通过。已备份并安装到本机「笔记」和「测试」，安装文件 Hash 与包一致，配置 Hash 未变；记录保存在 `dist/installation-0.2.14.json`。
- 浏览器使用实际设置组件、宿主样式和模拟后台状态，真实操作滚动、焦点和光标：27 次更新后 body 滚动仍为 1137，焦点和草稿 `13` 保留；另 43 次更新后滚动仍为 512，值 `115`、光标位置 1 和另一字段草稿均保留。期间包含每三次一次的配置结构更新。
- 本机浏览器证据保存在 `dist/layout/ui-refresh-stability.json` 和同名 PNG；模拟值不包含真实账号、凭据或笔记。
- 浏览器验证不等于真实 Obsidian 窗口或 iPad 前后台验收，需本机安装后复测。未把界面更新稳定性测试称为真实百度传输验收。

## English

Requests were already asynchronous. Whole-settings rebuilds on task state changes, periodic history-list recreation and automatic task replacement disrupted interaction. Version 0.2.14 updates existing status/control/file nodes, preserves current interaction state only when structural changes require a rebuild, and guards stale/closed modal responses.

Text drafts remain editable during background work; configuration submissions remain guarded. Edits made while a save is pending survive its response. History keeps the selected task; the transfer center offers an explicit latest-task action while a previous list is being read. File-tree expansion remains under user control. Requests and sync decisions are unchanged.

All 217 automated tests passed. Browser tests using the actual renderer and synthetic background state retained real scroll/focus/draft/caret state across repeated updates. Native Obsidian, iPad and live Baidu acceptance remain separate.
