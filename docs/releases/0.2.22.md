# 0.2.22 本地预览：双端可靠性与性能证据

日期：2026-10-20。基线：0.2.21 (`daf4885dd4d2a4819e4f70f6794bb58b9ff0a74b`)。本轮仅本地交付，社区发布需要另行授权。

## 已实现

- 文件与空目录版本分别计数：枚举、分页、缓存命中、正文读取及字节、缓存保存失败/成功次数、各阶段耗时。未变化时继续不下载历史正文、不重写缓存。
- 最近 30 条本机任务保存白名单请求分类（次数、失败、耗时、最长请求、未结束数）及任务类型，手动/自动/恢复可区分；HTTP 200 内的固定百度错误码也计为失败。
- `ScanSummary` 仍为版本 1。旧记录缺少字段显示“未记录”，损坏的可选字段单独忽略，不阻断历史或同步。旧的文件统计字段含义不变。
- 并行检查实时显示双方状态。文件先结束时显示“文件检查完成，等待目录检查”；检查失败等待另一路结束后显示失败，不报告无变化。预览只在双方成功后就绪。
- 等待共享请求额度、限流倒计时和暂停后的原生请求排空均有说明。仅更新原有文本节点，保留输入、滚动、搜索及展开状态；无变化自动检查仍安静。
- 补上目录预检失败的进度收尾；暂停/连接切换后不使用旧预检结果开始新传输。旧连接的统计与进度回调不能更新新连接界面。
- 只读双端数据校验命令，确定性的 100 文件/10 空目录生成器、独立 25 MiB 附件，以及不会随日常任务轮转的专项报告导出。
- 专项性能采样明确场景和任务类型；版本/平台/任务类型/场景/文件数分别分组，至少 10 次才报告 P95；日常汇总明确缺少初始化标签，不能充当受控验收。

## 兼容与默认值

不修改云端格式、配对码、授权、绑定或用户设置，不增加远程索引。无需重新授权或导出配置。文件并发默认 8、可设 1–32；电脑分片默认 2、可设 1–4，移动端 1；电脑上限 512 MiB、移动端 20 MiB，原有合法自定义值保留。删除与自动同步保留用户当前选择。

### 本轮模拟数值

| 文件数 | 冷读取中位数：0.2.21 → 0.2.22 | 无变化中位数 | 无变化请求数 | 历史正文读取 / 缓存写入 |
| --- | --- | --- | --- | --- |
| 7 | 62 → 55 ms | 32 → 33 ms | 7 → 7 | 0 / 0 |
| 100 | 176 → 181 ms | 39 → 46 ms | 7 → 7 | 0 / 0 |
| 1000 | 1448 → 1446 ms | 95 → 116 ms | 18 → 18 | 0 / 0 |

每组新旧交替 10 轮、注入 3 ms 请求延迟，包含完整样本与 P95，不是百度网速。1000 文件热扫描出现 21 ms 的中位数差异，因此另做了[不注入等待的对照](../benchmarks/0.2.22-no-delay.json)：热扫描 64 → 62 ms、冷读取 167 → 166 ms。它未显示稳定的统计计算开销上升，提示计时器/宿主负载会影响短任务；这属于推断，真实平台差异仍需真机采样，不把差异写成提速结论。

复现：分别运行 `node --experimental-strip-types scripts/benchmark-reliability.mjs compare 7 10 3`，将 7 换成 100 和 1000，再运行 `node scripts/collate-reliability-benchmark.mjs`。无等待对照将最后参数设为 0；非默认延迟使用独立文件名，避免覆盖主对比。

## English

This local preview separates file/directory scan statistics, persists whitelisted request categories and task types, and explains parallel preflight, quota waits, retry countdowns and draining native requests. Directory-only failures now end progress truthfully. Paused or invalidated preflights cannot start transfers, and callbacks from previous connections cannot update a new connection's progress.

Version-1 summaries remain compatible: invalid optional fields are ignored independently; absent fields display “not recorded”. Remote formats, credentials, pairing, bindings and user defaults remain unchanged. There is no remote index or telemetry.

The preview includes deterministic synthetic fixtures (100 common files, 10 empty-directory nodes, optional 25 MiB desktop attachment), a marker-gated read-only verifier usable on iPad, permanent special reports, and explicitly labelled performance samples. Group by version, platform, task type, initialization scenario and corpus size; use one network environment per input folder. P95 requires ten or more samples. Request times are concurrent cumulative measurements, not task wall time.

The 281 passing automated checks and paired 0.2.21/0.2.22 synthetic comparisons are separate from native validation. Real Baidu speed, Windows/iPad transfers, lifecycle, multi-vault isolation and natural renewal of migrated credentials remain pending. Follow the [bilingual acceptance checklist](../acceptance/0.2.22.md). No community publication is authorized for this preview.
