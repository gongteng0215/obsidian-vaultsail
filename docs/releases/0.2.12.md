# 0.2.12 · 云文件目录树 / Cloud file tree

本地预览，最低 Obsidian 1.11.4，尚未发布社区。查看云端文件按笔记相对路径分组，不改变云端存储格式。

- 目录优先排列，显示下级文件路径数量；默认展开第一层，子目录可独立展开或折叠。
- 提供全部展开、全部折叠和路径搜索。搜索保留并展开匹配文件的父目录，清空搜索后恢复目录展开选择。
- 目录子项和文件版本详情按需创建；展开与搜索复用本次已加载的版本，不追加网盘请求。
- 文件展开后保留完整路径、内容大小、设备/版本标识与内容对象地址。冲突分支、删除记录及已删除文件与同名新目录同时存在的情况均保留显示。
- 紧凑行高，长路径换行，深目录控制缩进；使用原生可聚焦的展开控件，支持键盘操作。空库与搜索无结果分别提示。
- 不改变自动同步、删除开关、绑定、授权或用户配置。

214 项自动化测试、类型检查、生产构建与三文件 ZIP 校验通过。验证覆盖目录分组、自然排序、父目录搜索、冲突/删除保留、展开折叠、延迟创建、文本安全与实际插件入口。本地浏览器使用实际渲染组件、Obsidian 样式和示例数据检查桌面与窄窗口/130% 字号；不代表 iPad 真机验收。已备份并安装到本机「笔记」和「测试」，安装文件 Hash 与包一致，配置 Hash 未变；记录保存在 dist/installation-0.2.12.json。

Local preview requiring Obsidian 1.11.4; not published to the community. Cloud files are grouped by logical note paths without changing cloud storage formats.

- Folders sort first and show descendant file counts. The first level starts expanded; nested folders can be toggled independently.
- Expand/collapse-all controls and path search retain matching ancestors. Clearing search restores folder expansion preferences.
- Directory children and version details render on demand. Browsing/searching uses the loaded snapshot without additional provider requests.
- Version details retain paths, sizes, device/version identifiers and blob locations. Concurrent versions, deletion records and a deleted file sharing a name with a new directory remain visible.
- Compact rows, wrapping paths, bounded indentation and native keyboard-accessible disclosures support narrow views. Empty vaults and empty search results have distinct messages.
- Sync settings, deletion policy, bindings, authorization and configuration are unchanged.

All 214 tests, type checking, production build and three-file ZIP verification passed. Coverage exercises grouping, natural sorting, ancestor-preserving search, conflict/deletion preservation, toggles, lazy rendering, safe text rendering and the actual plugin entry. Browser layout checks use the production renderer, host styles and synthetic data; native iPad acceptance remains separate. Both local vault installations were backed up and updated; asset hashes match the package and configuration hashes are unchanged.
