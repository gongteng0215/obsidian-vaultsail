# 0.2.21 本地预览：文件作为目录树叶子

日期：2026-10-20。本次包含 0.2.19 性能优化和 0.2.20 已删除路径筛选，尚未提交社区。

- 只有文件夹使用可展开的树形行和箭头，保留原有展开、折叠、搜索和惰性加载。
- 文件显示为普通叶子行，显示文件图标、名称、大小或冲突状态，没有展开箭头和下级节点。
- 文件行提供“查看版本”按钮，在独立窗口查看路径、设备、版本与删除记录；关闭后返回原列表。
- 搜索、已删除筛选、滚动保留及空目录显示继续有效。“全部展开/折叠”仅控制文件夹。
- 移动端版本按钮保留至少 44 px 的点击高度。

本次仅调整云端列表交互，配置、授权、绑定、云端格式与同步行为保持兼容。

验证覆盖文件无 details/summary、名称点击不展开、文件夹惰性加载、独立版本窗口打开/关闭、冲突与删除记录查看，以及筛选与滚动。271 项自动化测试通过，类型检查、构建和三文件 ZIP 随本机安装核验；原生 iPad 仍待验证。

## English

Only folders have expandable tree rows. Files are ordinary leaves with an explicit View versions button that opens a separate dialog. Search, deleted-file filtering, folder expansion, lazy rendering and scroll preservation remain available. Configuration, authorization, bindings and synchronization formats remain compatible. This local preview includes 0.2.19 and 0.2.20 changes and has not been submitted to the community directory.
