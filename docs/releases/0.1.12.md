# VaultSail 0.1.12

通过百度网盘同步笔记与附件，支持一键双向同步、内容校验、并发版本保留和密码加密设备配对。电脑完成授权后，可将连接导入另一台设备，无需重复网页登录；导入时自动验证账号、云端库和本设备的小文件传输权限。

本次整理界面与使用说明，移除测试预览标识，修正过时冲突描述，并准备 Obsidian 社区目录提交资料。作者信息统一为 gongteng0215，安装文件包含项目及运行时依赖的 MIT 许可。

## 安装

- 最低 Obsidian：1.11.4。
- 下载 ZIP，或下载三个独立插件文件：main.js、manifest.json、styles.css。
- 放入当前知识库配置目录的 plugins/vaultsail/，关闭再启用插件。默认配置目录为 .obsidian。
- 社区目录提交/审核是独立流程，本次 GitHub 发布不代表已经在 Obsidian 插件市场上架。

## 验证与边界

- 86 项自动化测试、TypeScript 检查、生产构建及安装包文件检查通过。
- 单文件上限 20 MiB，传输并发 1，手动触发，删除传播默认关闭。
- 配对配置采用密码加密；云端笔记内容尚未端到端加密。
- 不提供正文自动合并或持续移动后台同步。
- 真实 iPad 导入、真实 100 文件跨端及双设备长期令牌续期尚未由开发者完成验收，不能把模拟结果当成实机认证。
- 平台撤销授权或刷新令牌失效时，需要从仍连接的设备重新导出，必要时重新授权。

凭据由用户自行配置并保存在本设备 SecretStorage；不要在反馈中发送真实密码、配对码或授权令牌。
