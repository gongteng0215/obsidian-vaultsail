# 0.2.20 本地预览：隐藏已删除云文件

日期：2026-10-20。本次包含 0.2.19 的性能优化，尚未提交社区。

- 云端文件树默认只显示仍有有效内容的路径；全部有效头版本都是删除记录的路径默认隐藏，改名留下的旧路径同样处理。
- 增加默认关闭的“显示已删除”开关，按需查看删除记录；每次重新打开列表恢复默认隐藏。
- 文件计数、搜索及推导出的父目录遵循同一筛选条件；独立存在的有效空目录仍显示。
- 修改与删除并发且仍有有效内容时，保留冲突项；多个删除头版本统一显示“已删除”，避免错误显示为零内容版本冲突。
- 切换筛选保留滚动、搜索和已展开的内容。只有删除记录时，明确提示已隐藏，不误报首次尚未上传。

删除记录及历史内容继续用于跨设备同步和恢复。本次修改列表显示，不更改删除传播开关、云端版本、授权或库绑定。

验证：云树/DOM 回归覆盖默认隐藏、按需查看、搜索与计数、删除路径与有效目录同名、删除/修改并发、多删除头、惰性渲染、滚动与展开状态，以及纯删除记录的提示。271 项自动化测试通过，类型检查与构建随安装包核验；原生 iPad 仍待验证。

## English

The cloud file tree hides paths whose current heads are all deletion records by default. A “显示已删除” (Show deleted) checkbox reveals them when needed. Counts, search and inferred folders follow the filter; valid empty directories remain visible. Concurrent update/deletion branches remain visible as conflicts, while multiple deletion heads are correctly marked deleted. Filter changes preserve scrolling, search and open details. Tombstones and historical content remain available for synchronization and recovery. Existing settings, authorization and bindings are preserved.
