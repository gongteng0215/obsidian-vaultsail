# VaultSail 0.1.15 预览测试版

修复 iPad 导入配对码时，小写 `vsail:1:` 被误当成旧版 JSON、尚未解密就提示“配置文件无效或版本不支持”的问题。固定前缀兼容大小写，配对码兼容空格、制表符与换行；密文大小写和密码原样保留，认证加密、大小限制与未知版本拒绝行为保留。配对码及密码输入关闭自动大写、自动纠正和拼写检查。

在 iPad 的 BRAT 中选择 `gongteng0215/obsidian-vaultsail` 的 `0.1.15` 版本更新，关闭再启用 VaultSail 后重新导入；无需卸载或清除配置。有效期内的旧加密配对码保持兼容。也可下载 ZIP 手动覆盖三个插件文件。

确认导入时实时显示账号验证、读取云端库、上传/下载校验文件、保存本机密钥等步骤。原生异常仅显示固定步骤和白名单错误类型，脱敏诊断记录步骤标识，不显示原始响应、URL、令牌或密钥。第二张真实 iPad 截图已经到达确认步骤，证明解密通过；其后失败的具体原因仍需更新后在设备重试定位，不能仅凭旧版通用错误判定为网络或权限问题。

88 项自动化测试、类型检查、构建和 ZIP 校验通过，含小写前缀、换行粘贴的模拟完整导入、篡改拒绝、原生账号/密钥保存异常分类及失败时原连接保留。真实 iPad 重试、真实双端长期续期仍待验收。
