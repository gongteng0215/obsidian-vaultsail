# 0.1.12：电脑授权一次，iPad 导入连接

默认导出密码加密的配对码，包含自己的 AppKey、SecretKey、访问令牌、刷新令牌、令牌到期时间、应用目录、账号绑定指纹及云端库 ID/名称。iPad 导入后自动验证并连接，授权仍有效或能正常刷新时无需网页登录。

设备 ID、源设备的密钥引用、同步基线、任务队列、恢复点和删除开关不迁移。解密后的凭据写入目标设备的 Obsidian SecretStorage；`data.json` 只保存配置及密钥引用。

## 电脑导出

1. 安装 0.1.12，完成授权并绑定要共享的云端库。
2. 打开「连接与授权」→「把连接带到 iPad」→「导出配对配置」。
3. 设置至少 10 个字符的配对密码，再输入一次确认，点击「生成加密配对码」。密码中的空格保留，不自动删去。
4. 点击「复制配对码」发送给自己的 iPad；或者「保存加密文件到库」，通过文件/AirDrop 传送 `VaultSail-配置/*.vaultsail`。文件与文本装的是同一份密文，目录强制排除笔记同步。
5. 在 iPad 输入相同的密码。配对码 24 小时内可导入，过期后在电脑重新生成；密码不保存到插件配置或导出文件。

## iPad 导入

1. 在目标 iPad Vault 中安装、启用 VaultSail 0.1.12，Obsidian 至少为 1.11.4。
2. 点击「导入配对配置」，选择 `.vaultsail` 文件或粘贴 `VSAIL:1:` 开头的配对码，输入配对密码。
3. 点击「检查并导入」，核对解密后显示的云端库，再确认导入。
4. 插件用迁移的授权读取实际账号、核对账号指纹、读取库标识/格式，并完整枚举应用根目录。必要时使用迁移的刷新令牌续期，不打开授权浏览器。
5. 在本设备自动上传、下载并校验 1 KB 隔离校验文件，通过后保存密钥引用与已验证绑定。失败时保留原连接。
6. 显示「配对成功」后可直接「开始同步」，或者先「预览下载」查看清单。配对本身不会自动上传笔记。

1 KB 检查仅证明本次连接的小文件上传下载能力，不代替 4 MiB/20 MiB 完整验证。完整「文件传输权限验证」仍可手动运行；诊断区分 `pairing-local-probe` 与 `full-roundtrip`。校验文件保留在 `vaultsail-probes/<随机ID>/pairing.bin`，可以自行清理。

旧版 JSON 文件仍支持导入，但它不含密钥或授权，仍需本设备登录。不能把旧版 JSON 改后缀就变成免登录配对码。本地 Vault 名称可以不同，两端绑定同一个远端库 ID 即可。导入默认关闭删除传播。

## 加密与授权边界

独立实现 AES-256-GCM，PBKDF2-SHA-256 600,000 次派生，随机 16 字节盐及 12 字节 IV。格式版本和头部也通过 GCM 认证，固定参数，不接受明文凭据、未知版本或较弱参数回退。密文上限 64 KiB、导入窗口 24 小时；这不是单次使用码，也不会自动撤销已经导入的授权。

持有配对码和密码即可迁移授权，请只交给自己的设备。平台撤销授权、刷新令牌失效或应用资格变更时，加密不能使无效授权继续可用；应从仍连接的电脑重新导出，必要时在电脑重新授权。两台设备各自保存续期结果，但百度是否允许同一刷新令牌长期多端复用，仍以用户应用真实行为为准，尚未实测。普通网络错误不会清除可重试的本地授权。

这里只加密配对配置，云端笔记内容仍按当前 blobs 格式保存；不是笔记端到端加密。研究了参考项目 [配对实现](https://github.com/owl234/obsidian-baidu-netdisk-sync/blob/main/src/crypto/configShare.ts) 与 [导入界面](https://github.com/owl234/obsidian-baidu-netdisk-sync/blob/main/src/ui/configShareModal.ts)，本项目不兼容其配对码，不直接复制其源码。

## 存放位置与进度

「云端知识库」显示“我的应用数据/…”完整路径，支持复制。「查看云端文件」列出原笔记路径及对应的 blobs 对象和并发版本。工作台显示扫描、上传、回读校验、发布、下载和本地写入阶段；文件数含已处理的跳过项，内容大小是已校验的逻辑内容，不是实际网络流量。只有执行成功才更新最近完成记录。后台挂起不承诺持续同步。

## 验证边界

86 项自动化测试通过，包括独立实现 AES-GCM 解密互通、随机密文、密码错误/篡改/过期、字段白名单、文件选择与确认流程、模拟免登录导入、自动权限验证、重启恢复、账号不匹配、下载损坏和部分保存失败回滚。

真实 iPad 文件选择器、SecretStorage/Web Crypto、真实双设备令牌续期、100 文件跨端校验及前后台切换仍需实际设备验收。开发者不读取用户真实密钥或令牌来代替验收。
