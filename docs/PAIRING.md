# 0.1.10：把电脑配置带到 iPad

配对配置包含百度 AppKey、应用目录及云端库 ID/名称。它不会复制 SecretKey、密钥引用、授权令牌、账号标识、设备 ID、同步基线、待执行队列或删除开关。

## 电脑端导出

1. 在电脑的 VaultSail 设置中完成应用配置，最好先绑定要共享的云端库。
2. 打开「连接与授权」→「把配置带到 iPad」→「导出配对配置」。
3. 选择「保存配置文件到库」，文件位于本地笔记库的 `VaultSail-配置/`；也可以直接复制配置文本。
4. 把 JSON 文件通过你使用的文件传输方式交给 iPad。此文件目录强制排除笔记同步，不会成为云端笔记。

## iPad 导入与连接

1. 在目标 iPad Vault 中安装、启用 VaultSail 0.1.10，Obsidian 至少为 1.11.4。
2. 点击「导入配对配置」，在文件选择器中选 JSON，或粘贴复制的配置文本。
3. 检查显示的应用目录与云端目标，点击「检查并导入」并确认。导入会停止旧任务并断开本地授权；笔记内容保留。
4. 在 iPad 保存应用自己的 SecretKey，点击「连接百度网盘」，在百度官方页面登录并授权。SecretKey 需要在该设备保存，电脑令牌不会被导入。
5. 在「云端知识库」中点击「验证并绑定导入库」。这一步从当前授权账号的实际目录读取库标识与格式，导入的 ID 本身不代表验证成功。
6. 在 iPad 运行「文件往返测试」，通过后点击「预览下载」，检查清单后执行。

本地 Vault 名称可以与电脑不同；两端绑定相同的远端库 ID 即可配对。设备身份、任务、恢复点与最近完成记录均由本设备独立维护。导入默认关闭实验性删除传播；正常双向同步可用。

## 查看实际存放位置与进度

「云端知识库」显示完整的“我的应用数据/…”路径，支持复制路径。「查看云端文件」列出原笔记路径及每个有效版本所对应的 `blobs` 内容对象；多个并发版本会标记冲突。

工作台和传输预览显示扫描、上传、回读校验、发布记录、下载与本地写入阶段。文件计数包含跳过或冲突的已处理清单项；内容大小累计已完成的上传、下载及冲突副本校验内容，不代表网络线上总字节数。预览结束显示“尚未传输”，只有执行成功才更新当前设备的最近完成时间。

耗时包含文件扫描、网络请求、回读校验和状态保存；应用后台挂起时不会承诺持续工作。脱敏诊断的最近传输摘要只含时间、文件数、内容大小与耗时，不含文件名或正文。

## 验证边界

配置的导出、文件选择/粘贴导入、独立设备身份、模拟授权及重新绑定已经通过自动化界面测试。真实 iPad 文件选择器、官方登录交互、真实 100 文件跨端校验及前后台切换仍需在实际设备验收。
