# 0.1.15 使用说明

本版本已实现用户自行配置应用的授权与手动文件传输。模拟验证不等于百度真实应用权限验证；真实账号与 iPad 尚未由开发者验收。

第二台设备可按 [加密配对流程](PAIRING.md) 导入电脑连接，不再要求重填密钥、重复网页登录。插件自动验证账号/库及本设备 1 KB 往返后允许同步；旧版 JSON 仍需独立授权。配对加密只保护迁移凭据，云端笔记尚未加密。

## 安装或升级

社区目录暂停分发，先完成双端实测。iPad 在 BRAT 中添加 `gongteng0215/obsidian-vaultsail`，选择 `0.1.15` 预览版并安装或更新；更新后关闭再启用 VaultSail，无需卸载。该版本修复小写配对码前缀和换行粘贴的识别问题，兼容仍在有效期内的旧加密配对码。

需要 Obsidian **1.11.4 或更新版本**。关闭 VaultSail，把发布 ZIP 解压至测试 Vault 的 `.obsidian/plugins/`，确认三个文件位于 `.obsidian/plugins/vaultsail/`，然后重新启用插件。

使用自定义 Obsidian 配置目录时，将 `.obsidian` 替换成实际配置目录。旧版的远端标识会保留，但必须重新选择一个已验证的云端库。

## 应用与登录

1. 在 [百度开放平台](https://yun.baidu.com/open/platform) 申请自己的应用与文件接口权限。接入资格和权限以平台实际审核为准。有百度账号并不代表已获得接口资格。
2. 打开 Obsidian → 设置 → VaultSail，选择「百度网盘」。填写自己的 AppKey，点击保存。
3. 在「SecretKey」密码框粘贴应用密钥，点击「保存密钥」。插件把它保存到专用的本地密钥存储，普通配置只保存引用；不把密钥、令牌或密码发给开发者。保存后显示「已保存至本地密钥存储」。旧版若选中了授权会话项，需要重新保存一次 SecretKey，AppKey 无需重填。
4. 应用目录默认填入并保存为 `/apps/VaultSail`；原配置为空时也会自动补齐。已有自定义目录保留。若平台给应用授权的目录不同，将它修改为实际获准目录并保存。留空保存会恢复默认目录。
5. 点击「连接百度网盘」，按钮先显示「正在申请授权」，取得设备码后自动请求打开百度官方页面。输入设置页突出显示的验证码并授权；浏览器未自动弹出时点击「打开官方授权页面」。各设备独立进行此操作。

账号密码只在百度官方页面输入。设备码明确不受支持时，插件才显示备用授权码入口；网络失败不会自动切换方式。授权并不代表上传下载权限已经通过。

AppKey、应用目录或密钥变更会断开旧连接并清除旧绑定。SecretKey 与会话令牌使用不同的存储项；断开本地连接清除令牌但保留应用密钥。百度端撤销授权需要在百度账号管理页面操作。

## 0.1.3 工作台与修复

设置页分为「连接与授权」「云端知识库」「传输与恢复」三个标签。应用参数与授权操作集中在首个标签；实验同步与诊断默认折叠。

0.1.2 清理会话时可能创建一个空密钥项，原生密钥选择控件仍显示圆点；若用户选择该会话项，配置变更又会将它清空。0.1.3 不再创建空会话项，应用密钥通过专用输入保存，且明确区分 AppKey 未保存、密钥关联错误和密钥值为空。登录授权不再以应用目录为前置条件，目录在文件传输前配置。

0.1.4 修复授权按钮交互：自动请求打开浏览器，按钮旁持续显示申请/等待状态和大号设备验证码；请求超过 15 秒报超时，取消可立即结束本次逻辑会话。切换到浏览器不会把授权状态误写成「传输暂停」。已验证用户应用可以获取设备码，但未代替用户登录或验证实际 Token 交换。

0.1.5 按用户要求增加默认应用目录 `/apps/VaultSail`，自动补齐空配置并保存，保留已有自定义目录。默认值不等于该路径的接口权限已经通过，仍以用户本地往返验证为准。

## 本地文件往返验证

先执行「检查只读访问」，再点击「验证文件传输」并确认。插件在 `vaultsail-probes/<随机ID>/中文测试/多层目录/` 创建 0 B、1 KB、4 MiB、20 MiB 的校验文件，上传后下载并比较 SHA-256。不会读取或上传本地笔记。

测试目录保留供检查；可自行在网盘中清理。只有本设备、当前应用目录及账号的测试通过，才允许执行笔记传输。配额验证结果单独报告，不伪装成已验证。限流和权限失败会显示不同原因。

## 创建、绑定与传输

1. 在「云端知识库」创建一个云端库，或在「查看已有库」中绑定。0.1.6 在尚未绑定时点击传输会直接打开创建或选择云端库的引导，随后可以验证文件传输。绑定本身不上传笔记。云端 UUID 用于配对，本地库可以使用不同名称。
2. 在测试库内放入 Markdown、图片或 PDF 文件，点击「预览上传」。检查清单后执行。
3. 在另一设备的空白测试库导入电脑的加密配对码，自动验证连接和绑定后点击「预览下载」；也可以自行配置应用并独立授权、运行往返验证及绑定。
4. 已有基线的单边修改自动传输；并发冲突自动保留全部竞争内容在 `VaultSail-conflicts/`，不需要先手动裁决才能继续同步。手动统一版本是可选操作。

单文件最大 20 MiB，并发为 1。隐藏目录、自定义 Obsidian 配置目录、`node_modules`、恢复目录和内部状态不参与同步。文件夹中仅有被排除内容时不会上传空目录。

云端保存的是 `vault.json + blobs + ops` 格式的版本存储，插件下载后还原正常笔记目录。插件不直接镜像用户的其他网盘文件，也不向开发者服务器传输数据。

## 双向同步与恢复

正常双向同步可直接点击「开始同步」，仍处于预览版且尚未通过真实双设备验收；也可以先预览。删除传播默认关闭，需要单独开启实验开关；本地删除保存恢复点并移入回收区，云端只发布删除记录，不永久清理对象。

唯一的同内容重命名可保留文件身份；一边改名一边改内容、多个相同内容候选不能确定时保守处理为新增与保留旧版本。同一文件的并发重命名会暂停应用，保留云端分支，需要后续处理。

网络中断后点击「恢复未完成任务」。如果恢复因新的本地编辑停止，可选择「结束旧任务并重新预览」，保留内容与恢复点后重新判断差异。不要手工删除内部状态来跳过错误。

「查看恢复点」可以恢复旧内容，恢复前也会备份当前版本。恢复点及暂存位于 `.vaultsail-state/<本设备ID>/`，插件不会自动清理它们。大量修改可能增加本地及云端占用，应根据实际配额安排测试。

iPad 后台运行不保证持续传输。应用转入后台会请求暂停；回到前台检查本地日志并提示恢复，不自动执行笔记同步。

## 验证边界

- 自动化验证：授权、协议适配、100 文件往返、100 个可重复中断场景、并发冲突、删除保护、重命名、两个远端库隔离、中文设置页及状态写入恢复。
- 待用户本地验证：自己的应用资格与授权、百度真实接口、安装后实际交互、Windows/iPad 跨端、iPad 前后台切换 20 次。
- 「查看脱敏报告」不包含账号、文件名、笔记正文或凭据，可用来描述验证结果。
- 不支持端到端加密、实时协作、Markdown 正文自动合并、GB 级附件或持续后台同步。

0.1.7 修正百度响应格式兼容：分片上传可仅返回 MD5，其他接口仍要求明确状态码；同时识别 errno、error_code、error_no，显式错误不会被成功字段覆盖。错误显示读取目录、创建目录或上传分片等具体步骤，不显示凭据及原始响应。

0.1.8 减少重复目录查询，复用已校验且远端指纹一致的库信息与操作记录；小文件模拟请求合计从 60 次降到 31 次。完整内容校验、实时版本枚举、单文件限制与并发 1 保留。无需修改原有云端数据或重新保存密钥。详细比较见 [传输性能记录](PERFORMANCE.md)。

0.1.9 新增阶段进度、内容大小与耗时、云端路径和文件版本清单，以及不含密钥/令牌的 JSON 配对配置导出导入。iPad 完成自己的授权与权限验证后绑定同一个云端库。操作步骤见 [设备配对配置](PAIRING.md)。

0.1.10 将工具栏主入口改为真正的一键双向同步，普通修改自动传输，冲突自动保留可见副本与云端分支。单向传输也使用基线识别正常更新。删除仍默认关闭，文件上限和并发保留。升级后首次扫描建立历史记录缓存，后续重启无需重新下载所有旧记录。机制见 [同步与冲突](SYNC.md)，请求比较见 [性能记录](PERFORMANCE.md)。
