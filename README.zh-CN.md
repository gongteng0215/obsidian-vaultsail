使用自己的百度网盘，在多台设备间同步 Obsidian 笔记和附件，支持自动同步、版本保留、冲突处理与加密设备配对。

## 主要功能

- 手动或自动同步 Markdown、图片、PDF 等普通文件。
- 本地改动与云端检查统一排队，每个库独立保存队列，文件并发数可自行设置。
- 根据已验证基线、内容 Hash 和父版本关系判断变化，不靠设备时间决定覆盖。
- 自动合并具有共同祖先且修改兼容的 Markdown；重叠修改可在冲突编辑器处理，也可选择完整版本或保留两篇。
- 保留竞争内容和恢复副本，以 SHA-256 校验传输，恢复未完成任务。
- 用密码加密的配对码或文件迁移应用配置与授权，授权有效时另一台设备无需重复网页登录。
- 实时显示进度、扫描与传输耗时、请求数量和令牌刷新次数。

**0.2.0 当前支持百度网盘。** 插件直接连接百度官方接口，无需开发者自建的授权或同步服务器。当前设置与提示以中文为主。

## 使用要求与默认设置

| 项目 | 要求或默认值 |
| --- | --- |
| Obsidian | **1.11.4 或更新版本**，使用 SecretStorage 密钥存储 |
| 百度接入 | 自己的账号，以及获准使用所需接口的应用 |
| 应用配置 | 自己的 AppKey、SecretKey 和实际获准应用目录 |
| 自动同步 | 默认**关闭**，每个 Vault 单独开启 |
| 本地改动等待 | 停止编辑约 **2 秒**后处理；连续编辑最多合并等待 **15 秒** |
| 云端检查 | 默认 **60 秒**并加入少量随机延迟，可设 **30–300 秒** |
| 文件并发 | 默认 **8**，可设 **1–32**，大文件自动减少批次并发 |
| 单文件大小 | 最大 **20 MiB** |
| 删除传播 | 默认**关闭**，需单独开启实验选项 |
| 移动端后台 | 不提供持续后台同步 |

这些时间是任务调度间隔，不保证到点就传输完成。已有任务、网络异常、限流、后台挂起和暂停都会延长等待。0.2.0 自动化验证已通过，完整 Windows/iPad 双端、百度实际吞吐与长期多设备验证仍未完成。

## 安装与升级

### 从社区安装

1. 打开 Obsidian「设置 → 第三方插件」，按需启用第三方插件。
2. 在社区搜索 **VaultSail**，安装并启用。
3. 已安装时点击「检查更新」，更新 VaultSail。
4. 关闭再启用插件，确认显示版本为 **0.2.0**。

**每台设备上，每个需要同步的本地 Vault 都要安装并启用插件。** 登录 Obsidian 账号不会自动安装 VaultSail 或连接百度。不同 Vault 可以复用同一个百度账号，同时绑定各自独立的云端库。

使用新版合并流程前，两台设备都更新到 0.2.0。普通升级保留配置与连接；仅升级插件不需要重新导出仍有效的配对码。

### 手动安装与 BRAT

从 [发布页](https://github.com/gongteng0215/obsidian-vaultsail/releases/tag/0.2.0) 下载 ZIP 或三个独立文件，关闭 VaultSail 后放入以下目录，再启用：

```text
<你的笔记库>/.obsidian/plugins/vaultsail/
├── main.js
├── manifest.json
└── styles.css
```

使用自定义配置目录时，将 `.obsidian` 换成实际目录。覆盖插件文件时保留已有 `data.json`。

iPad 和电脑也可使用 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，添加 `gongteng0215/obsidian-vaultsail`，指定 `0.2.0`。

## 第一次连接

设置页分为「**连接与授权**」「**云端知识库**」「**传输与恢复**」三个标签。

### 1. 保存自己的应用配置

在「连接与授权」选择百度网盘，填写 AppKey 后点击「**保存**」；填写 SecretKey 后点击「**保存密钥**」。仅输入不会保存，请检查界面的已保存提示。

应用目录填写自己应用实际获准的路径。默认 `/apps/VaultSail` 只是默认存放位置，不代表百度已授予访问权限；实际目录不同时需要修改。

百度账号用于登录，开放平台应用用于获取接口资格，两者不能互相代替。可从设置打开平台申请，准入与权限以百度实际审核为准。应用密钥只保存在自己的设备，无需发给开发者。

### 2. 授权百度账号

点击「**连接百度网盘**」，插件申请设备码并打开百度官方页面。在官方页面登录，按需输入插件显示的验证码。浏览器没打开时，点击设置中展示的官方授权链接。

账号密码只在百度官方页面输入。只有应用明确不支持设备码授权时，才提供浏览器授权码备用入口；普通网络错误不会自动切换方式。

### 3. 验证文件接口

先点击「**检查只读访问**」，再点击「**验证文件传输**」并确认。完整验证在隔离目录上传、下载约 24 MiB 校验数据，覆盖 0 B、1 KB、4 MiB 和 20 MiB 样本，并比较内容 Hash。

样本保留在应用目录下的 `vaultsail-probes/<随机ID>/`，可自行检查与清理，不包含笔记正文。「账号已授权」与「文件传输验证通过」是两个状态。

### 4. 创建或选择云端库

在「云端知识库」为独立的一组笔记「**创建新云端库**」，或查看已有库并选择目标。每个库有独立 UUID；两端本地名称可以不同。

填好应用目录不等于绑定云端库，单独填入旧远端 ID 也不能代替验证。切换账号、应用、密钥或目录后，需要重新检查连接与绑定。

### 5. 执行首次同步

可先「**预览上传**」「**预览下载**」检查变化后执行，或点击「**开始同步**」进行双向同步。工具栏云朵按钮同样开始同步。创建或绑定云端库本身不会上传笔记。

## 电脑、iPad 与其他 Vault 配对

配对迁移的是连接，不会把笔记内容打包导出。目标设备先安装 VaultSail。

| 使用目的 | 导出选项 | 导入选项 | 云端目标 |
| --- | --- | --- | --- |
| 另一个 Vault 复用百度账号 | 不开启「同时导出当前云端库」 | 不开启「绑定配对码中的同一个云端库」 | 导入后为该 Vault 创建或选择独立目标 |
| 两台设备同步同一组笔记 | 开启「同时导出当前云端库」 | 开启「绑定配对码中的同一个云端库」 | 两端使用同一个已验证远端 UUID |

1. 在已连接的源设备打开「**导出配对配置**」。
2. 按上表选择是否同时导出当前云端库。
3. 设置并确认至少 **10 个字符**的密码，生成配对码。复制代码或保存 `.vaultsail` 加密文件，传给自己的设备。
4. 目标设备打开「**导入配对配置**」，粘贴代码或选择文件，输入导出密码。
5. 选择是否绑定码中的云端库，检查并确认。插件检查账号、目录和 **1 KB 上传下载往返**，通过后替换连接；已有本地笔记保留。
6. 仅迁移账号时，为当前 Vault 创建或选择目标；同库配对时，核对名称后预览首次下载或同步。

默认只导出、导入账号。即使旧码包含云端库，也要明确勾选才绑定。设备 ID、基线、队列、恢复数据和冲突草稿不会迁移。导入连接后自动同步关闭，需在本机重新开启。

配对码生成后 **24 小时内**可导入，并非一次性码。拿到配对码和密码的人可以复用其中授权。授权撤销或刷新令牌失效时，需要从仍连接的设备重新导出，必要时重新授权。旧版明文 JSON 不含授权，导入后仍需登录。

配对采用 **AES-256-GCM**、**PBKDF2-SHA-256 600000 次派生**以及随机盐和 IV，保护迁移凭据，不加密云端笔记内容。兼容与失败处理见 [详细配对说明](docs/PAIRING.md)。

## 自动同步与队列

完成连接、绑定与文件验证后，在「传输与恢复」开启「**自动同步**」，每个 Vault、每台设备分别设置。

| 触发条件 | 处理方式 |
| --- | --- |
| 本地新建、编辑、删除或重命名 | 对相关路径排队，安静 2 秒后处理；连续编辑最多合并等待 15 秒 |
| 另一台设备发布变化 | 下一次前台云端检查时发现，默认 60 秒并加入少量随机延迟 |
| 插件启动或回到前台 | 自动同步开启时，核验未完成工作并安排完整检查 |
| 定期核验 | 自动同步运行期间，每 10 分钟安排完整检查 |
| 任务中再次点击「开始同步」 | 合并为后续检查，多次点击不会同时启动多个任务 |
| 应用切到后台 | 停止派发并请求暂停，已发出的请求可能继续完成 |

一个库同时只执行一个同步任务，任务内多个文件可并发。期间的新编辑继续排队，随后处理。下载触发的本地事件与已验证基线核对，避免无变化内容循环上传。

日常重新读取变化文件和受云端变化影响的文件；云端无变化的远端检查不会读取全部本地正文。远端历史仍需枚举，首次扫描、缓存指纹缺失时可能增加请求。

网络错误、限流会退避并尊重服务端等待要求；授权、完整性和无法安全恢复的错误会停止自动重试，等待处理。「**暂停当前任务**」在当前请求结束后生效。用户主动暂停会保持，需明确开始继续，回到前台不会解除用户暂停。

## 版本与冲突处理

VaultSail 使用已验证基线、内容 Hash 和父版本图，采用版本控制中的共同祖先思路。插件不运行 Git，也不把笔记存到 GitHub。

| 场景 | 处理结果 |
| --- | --- |
| 只有一端相对基线修改 | 重新核验后传输变化 |
| 两端内容相同 | 跳过重复内容，同内容分支可以收敛 |
| B 收到 A 的修改后继续编辑 | B 发布后继版本，A 可作为后续变化接收 |
| A、B 从旧版本独立编辑 | 保留双方分支，尝试有预算限制的 Markdown 三方合并 |
| 修改重叠或祖先不明确 | 保留竞争内容，列出冲突等待处理 |
| 删除与修改冲突 | 保留竞争内容；删除还需独立开启删除传播，并明确选择冲突结果 |

**不会按修改时间决定谁覆盖谁。** 即使两端在时间上先后编辑，如果后编辑的设备没收到前一台的变化，也可能形成分支。

自动合并适用于符合条件的 UTF-8 Markdown：每份输入、输出最大 **256 KiB**，行比较最多 **3000 行**、单个差异表最多 **200 万单元**。唯一共同祖先下的兼容修改可自动合并；重叠修改、两端都改 YAML 前置信息、祖先不明确和多个不同内容分支需确认。图片、PDF 和超出预算的文件选择完整版本。

打开「**查看待解决冲突**」，比较本机、可用共同祖先和各云端分支。可逐块选择一方或双方、编辑全文并确认手工合并完成、选择完整版本，或用不同文件名保留两篇正常同步的笔记。并发重命名需要选择最终路径。

关闭编辑器保存本机草稿。确认前版本有变时，停止提交并保留草稿。解决版本引用竞争分支，其他设备可接收结果。普通内容冲突未处理时，其他独立文件仍可同步。

`VaultSail-conflicts/` 中的副本排除同步；通过「保留两篇」创建的另一篇是正常同步文件，两者用途不同。

## 百度网盘里放在哪里

```text
<实际获准应用目录>/vaultsail/vaults/<远端库UUID>/
├── vault.json           # 库标识与格式
├── blobs/<sha256>       # 不可变内容对象
└── ops/<设备ID>/        # 不可变版本与操作记录
```

默认目录对应前缀 `/apps/VaultSail/vaultsail/vaults/`。在插件云端位置和版本列表查看实际路径与库 ID。

这里保存的是版本数据，下载时还原为正常笔记路径，`blobs` 不是按原文件名排列的镜像目录。插件不导入网盘其他位置的任意已有文件。当前版本不永久清理旧云端对象，网盘占用可能大于本地当前笔记大小。

## 文件范围、删除与恢复

支持不超过 20 MiB 的普通文件，包括 Markdown、图片、PDF、中文路径和零字节文件。排除带点号前缀的路径部分、当前 Obsidian 配置目录、`node_modules`、`Thumbs.db`、`VaultSail-conflicts/`、`VaultSail-配置/`，以及内部 `.vaultsail-state/`。主题、插件、配置和凭据不会作为笔记复制。

删除传播默认关闭，缺少文件不能直接成为删除另一端的依据。实验删除选项使用版本化删除记录和本地恢复数据，不永久删除云端内容对象。

下载先暂存并校验 Hash，再应用到笔记路径；替换前保留恢复副本。日志记录上传、发布、本地应用和基线进度，恢复时核验实际结果。

中断后使用「**恢复未完成任务**」。新编辑导致不能安全恢复时，选择「**结束旧任务并重新预览**」并检查新计划。「**查看恢复点**」可还原旧内容，还原前保留当前内容。恢复数据和草稿位于 `.vaultsail-state/<设备ID>/`，不会自动清理。不要手工删除内部状态来绕过错误。

## 性能与常见问题

| 现象或问题 | 检查方式 |
| --- | --- |
| 填了配置却提示未配置 | AppKey 点「保存」，SecretKey 点「保存密钥」，检查已保存提示 |
| 账号或目录未绑定 | 创建或选择已验证云端库，仅授权和填写目录还不够 |
| 没有自动同步 | 确认加载 0.2.0、已开启自动同步、文件验证通过、应用在前台，队列未暂停或阻断 |
| 另一台设备的改动没立即出现 | 对方先发布，本机再通过云端检查或手动同步发现 |
| 没有上传也扫描很久 | 查看云端扫描耗时、请求数和缓存统计，首次加载历史或缺少指纹可能增加请求 |
| 传输慢 | 区分扫描与传输耗时；并发 1–32、默认 8；大文件减少批次并发，网盘与网络限制仍存在 |
| 每次同步都重新授权吗 | 不会，复用已保存授权；接近过期或接口明确提示令牌无效时刷新 |
| 配对导入失败 | 检查版本、24 小时有效期、密码和失败步骤，只提供脱敏报告 |
| iPad 后台停止同步 | 不保证后台持续运行，保持 Obsidian 前台；返回后检查未完成工作 |

提高并发不会消除远端枚举和内容校验。等待请求期间持续显示耗时，完成验证后才累计已校验字节。[性能记录](docs/PERFORMANCE.md) 是历史模拟比较，不代表实际百度吞吐保证。

## 隐私与网络访问

密钥与令牌通过 **Obsidian SecretStorage** 保存，普通配置只存引用。请求直接发往百度 OAuth（`openapi.baidu.com`）、文件接口（`pan.baidu.com`、`d.pcs.baidu.com`）和 `baidu.com` / `baidupcs.com` 下受允许的 HTTPS 下载主机。

没有项目自建授权服务器、遥测、广告或插件自更新器。插件在库内枚举路径、读取同步内容，并写入传输结果、内部状态和恢复副本。只有用户请求复制时才写入配对码或路径，不读取剪贴板。

诊断导出不含凭据、账号标识、文件名、笔记正文和合并草稿。反馈不要附上 `data.json`、配对码、密码、SecretKey 或原始授权响应。**云端笔记尚未端到端加密**，配对加密只保护连接迁移。

断开本地连接清除本机授权，不代表已在百度撤销授权；远端撤销请使用设置中的官方授权管理入口。
